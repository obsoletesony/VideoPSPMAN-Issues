# VideoPSPMAN Issues

Public bug reports for **VideoPSPMAN**, the PSP video player by ObsoleteSony.

**[Report a bug / 不具合を報告](https://github.com/obsoletesony/VideoPSPMAN-Issues/issues/new?template=01-bug-report.yml)**

**Reports must come from physical PSP hardware. PPSSPP emulator reports are not accepted.**\n\nEnglish and Japanese reports are welcome. You only need to fill in the details you know. Screenshots and diagnostic logs are optional.

Before posting, check your attachments for personal information. Do not share passwords, Jellyfin access tokens, Quick Connect codes, private network addresses, session files, or copyrighted video files.

This repository is only for public reports. The VideoPSPMAN application source and internal development are maintained separately.

Website: https://www.obsoletesony.com/videopspman/
